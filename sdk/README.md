# @misonetwork/miso-party

Typed query helpers and transaction builders for Miso PartyOS and its Sui extensions.

## Install

```sh
npm install @misonetwork/miso-party @mysten/sui @mysten/move-bytecode-template @unconfirmed/ori
```

The package exposes the client, query, transaction, execution, view, type, and extension modules as explicit subpath exports.
